Tonic is a webpage designed to help beginner musicians improve their relative pitch through melodic dictation exercises. It builds off of an aural skills website designed by my professor, Dr. Dimitri Shapovalov; he supplied me with a lite version of his website to build off of, which can be found in the original-website-lite branch. The webpage focuses on implementing industry-standard notation software design principles and incentivizing the correct type of musical growth through its weighted/unweighted grading system.

A presentation of the project can be found [here](https://youtu.be/6X3YwGz2eQA).

This project served as my senior thesis for my BA in Computer Science at Carthage College. It was made with the guidance of Dr. Mark Mahoney, Dr. Elizabeth Zak, and Dr. Dimitri Shapovalov.
